# Event

防音ブースの構造設計について、床荷重とフレーム剛性の確認方法を整理し、設計方針を採用した。

# Knowledge Used

- Floor Load and Load Path
- Sheathed Frame Stiffness
- DIY Structural Load Check
- Japanese Building Structural Load References

# Design Result

採用した方針:

- 設計総質量は概算500 kgとして扱う
- 平均面荷重だけで床の安全性を判断しない
- 既存床への荷重経路を確認対象にする
- 木枠単体ではなく、合板を含む構面として水平変形を抑える
- ドア開口部は補強する
- 法令の積載荷重値を、そのまま設置可能重量として扱わない
- 実測寸法を施工後の製作寸法へ反映する

# Why This Is an Event

施工前の検討から、実際に採用する構造方針へ移行したため。

この判断は後続のフレーム施工、面材施工、ドア開口補強、床荷重確認に影響する。
